Interactive Program — 10 Numbers

A simple interactive web page built with HTML + JavaScript.
The program accepts exactly 10 real numbers (comma-separated, dot as the decimal separator), validates the input, and displays:

Min — the minimum value (highlighted)

Max — the maximum value (highlighted)

Average — rounded to 2 decimal places

User Guide

Enter exactly 10 numbers into the input field, e.g.:
12.5, 200, 999.9, 15, 20, 30, 40, 50, 60, 70

Click the "Calculate" button.

If invalid data is entered, the program will show an error message:

Fewer/more than 10 numbers

Wrong format (missing dot as decimal separator)

Numbers outside the 10–1000 range
→ You will be asked to try again.
